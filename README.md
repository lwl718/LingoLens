# LingoLens AI 实时翻译

小巧的浏览器划词翻译扩展（Manifest V3），连接 OpenAI 兼容的大模型 API 进行翻译。支持 Google Chrome 和 Microsoft Edge。

## 功能

- **划词翻译**：在网页上选中文字，自动弹出译文
- **弹窗翻译**：点击扩展图标，直接输入文本翻译
- **快捷键**：默认 `Alt+Shift+T` 翻译当前选中文字（可在浏览器扩展快捷键设置中修改）
- **右键菜单**：选中文字后右键翻译
- **多服务商**：内置 DeepSeek、OpenAI、OpenRouter 预设，也可填写任意 OpenAI 兼容接口（含本地接口）
- **结果缓存**：相同文本短期内不重复请求 API，省额度

## 安装

从本仓库的 [Releases](../../releases) 下载对应浏览器的 ZIP 包，解压到一个长期保留的文件夹，然后：

**Chrome**：地址栏打开 `chrome://extensions/` → 打开右上角"开发者模式" → "加载已解压的扩展程序" → 选择解压出的文件夹。

**Edge**：地址栏打开 `edge://extensions/` → 打开左侧"开发人员模式" → "加载解压缩的扩展" → 选择解压出的文件夹。

安装后请保留该文件夹，不要删除或移动；刷新已打开的网页后即可划词翻译。

## 配置

点击扩展图标打开设置，填写：

- **接口地址**：服务商的 chat/completions 端点
- **模型**：如 `deepseek-chat`、`gpt-4o-mini` 等
- **API 密钥**：你自己的密钥，仅保存在浏览器扩展本地存储中，不会上传到任何其他地方

## 目录结构

- `chrome/` — Chrome 版源码（v1.0.3）
- `edge/` — Edge 版源码（v1.0.2）

## 隐私

- 翻译请求只发送到你在设置中填写的接口地址
- API 密钥只保存在浏览器本地存储中
- 本扩展不收集、不上传任何用户数据
